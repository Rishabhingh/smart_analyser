# SMART ANALYSER

An intelligent offline desktop tool for pharmacists to build corporate reports with live chart preview and export.

# Features
- Pie / Bar / Line Chart preview
- Custom labels & colors
- Export as PNG
- 100% Offline - Tkinter GUI

# Tech
Python, Tkinter, Matplotlib

# Run
pip install matplotlib
python Smart_Analyser.py

# Build Exe
python -m PyInstaller --onefile --windowed --name "Smart Analyser" Smart_Analyser.py
