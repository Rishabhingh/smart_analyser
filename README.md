💊 smart_analyser
A smart desktop app analyses medical/pharma data, automate reports & boost productivity. Built with Python.

An intelligent offline desktop tool for pharmacists to build corporate reports with live chart preview and export.

✨ Features
Pie / Bar / Line Chart preview
Custom labels & colors
Export as PNG
100% Offline - Tkinter GUI

🛠️ Tech Stack
Python 3.14
Tkinter
Matplotlib
Pandas
OpenPyXL

🚀 How to Run
pip install -r requirements.txt
python smart_analyser.py
📂 Sample Data
Use sample_data.xlsx for testing, or select your own CSV/Excel file via Browse button.

🔨 How to Build Exe
pip install pyinstaller
python -m PyInstaller --onefile --windowed --name "Smart Analyser" smart_analyser.py
